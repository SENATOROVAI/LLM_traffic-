# Traffic Analyzer

**Гибридный анализ сетевого трафика на основе локальной большой языковой модели**

</div>

---

## Проблема

Объёмы корпоративного трафика растут быстрее, чем производительность инструментов анализа. Сигнатурные IDS не распознают новые угрозы, а облачные LLM-решения требуют передачи трафика во внешние сервисы — неприемлемо по требованиям ИБ.

## Решение

Разработан метод **гибридного анализа**, в котором локальная языковая модель выступает семантическим классификатором без передачи данных наружу:

```
pcap / pcapng
     │
     ▼
Schema Translator
двухуровневая нормализация → JSON Schema (NetworkEvent)
     │
     ▼
LLM Gateway  (Ollama · phi3:mini)
промпт → классификация + объяснение на естественном языке
     │
     ▼
Streamlit UI · результат локально, без облака
```

**Ключевые свойства:**
- Детерминированная трансляция pcap → структурированный промпт
- Локальное исполнение (Ollama + phi3:mini) — данные не покидают инфраструктуру
- Интерпретируемые объяснения к каждой классификации
- Модель угроз по методике ФСТЭК России 2021

## Результаты

Эксперименты на датасетах **UNSW-NB15** и **CICIDS2017**:

| Метод | Интерпретируемость | Без облака |
|---|:---:|:---:|
| ML-классификаторы (baseline) | — | ✓ |
| LLM-only (phi3:mini) | ✓ | ✓ |
| **Гибридный (TA)** | **✓** | **✓** |

Гибридный подход — единственный из рассмотренных, который сохраняет конкурентоспособное качество классификации и даёт **читаемые текстовые объяснения** каждого события без передачи трафика в облако.
